3 · What to record (one pass, five minutes)

  1. Open the test bench. Leave it on auto height — does the iframe grow with content, no inner scrollbar?
  2. Switch to a fixed height. Note the smallest height where nothing is clipped (report the number).
  3. If the component sets sandbox, add it in the bench and press “測試叫起 PayMe” — the widget reports whether the browser blocked it.
  4. Press the credit-card tile — it must leave the iframe (target="_top"), not render a page inside it.
  5. Fill the receipt form and submit — check Checks turns email_capture to PASS.
  6. Paste a GTM container ID, load it, re-run the steps — do the events appear in dataLayer?
  7. Press Copy test report and send it back.
