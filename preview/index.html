這 7 行就是自動高度的全部 —— 貼一次，所有用同類元件的頁面都會跟住內容調整高度 
<script>
window.addEventListener("message", function (e) {
  if (e.data && e.data.source === "fhf-taxcalc" && e.data.type === "resize") {
    var f = document.getElementById("fhf-calc");       // your iframe
    if (f && f.contentWindow === e.source) f.style.height = e.data.height + "px";
  }
});
</script>

沒有這段 script 也能運作 —— 但 iframe 會停在固定高度、內部滾動。有這段 script 就完全無滾動條。
